Speaker 2 • Engineering Architecture

End-to-End System Architecture

1. Edge Layer (ESP32-S3)

MicroPython firmware reads card UID via SPI, renders card UI on ST7789, emits audio feedback, and calls Supabase REST RPC over Wi-Fi.

mfrc522.py • st7789.py • portal.py

2. Cloud Database (Supabase)

Atomic PostgreSQL stored procedure (record_daily_attendance) validates enroll_id, checks today's records, and rejects duplicates.

PostgreSQL 15 • RLS Enforced • RPC Definer

3. Consumer Layer (Google Sheets)

Background sync worker catches database updates and pushes them to teachers' spreadsheets via Google Apps Script webhooks.

gsheet_sync_worker.py • Excel Exporter
Data Flow: Card Tap → MicroPython RPC → Atomic PostgreSQL Upsert → Audio-Visual Feedback → Google Sheets Webhook

Speaker 3 • Security Architecture

Enterprise Security & Data Integrity

🔒 Credential Isolation

Terminals hold only a public anon key restricted exclusively to the record_daily_attendance RPC function. Direct table access is blocked by Row Level Security (RLS).

🕐 Server-Authoritative Clock

Attendance timestamps are generated by PostgreSQL (timezone('utc', now())). Students cannot tamper with attendance times by spoofing device RTC clocks.

📋 Atomic Daily Constraint

PostgreSQL schema enforces UNIQUE (student_id, date). Duplicate network packets or multiple card swipes return ALREADY_MARKED with zero race conditions.

Speaker 4 • Proxy Prevention

Defeating Proxy Attendance

2.0s
Hardware Cooldown

Firmware blocks rapid consecutive card taps. Swiping multiple cards in a row triggers an alert lockout.

👁 High-Visibility Display

The ST7789 TFT prominently renders the student's Full Name, Enroll ID, and Class for 2 full seconds so teachers immediately spot proxy swipes.

🔊 Auditory Verification

Piezo buzzer emits 2 chirps for "Present!", 1 long tone for "Already Marked", and 3 rapid clicks for "No Data Found", giving teachers instant room-wide audio cues.
