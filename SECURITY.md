# Security Policy

## Supported Versions

We release patches and security updates for the current major branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this IoT project seriously. If you discover a security vulnerability or credential exposure risk:

1. **Do not open a public GitHub issue.**
2. Please report the issue privately through [GitHub Security Advisories](https://github.com/Jnyananjan/SNSAS/security/advisories/new) or by contacting the repository maintainer directly.
3. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept code.
   - Any proposed remediation or patch.

We will review reports promptly and publish patches with proper attribution.
